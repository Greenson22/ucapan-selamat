# 02: Animasi entrance slide (fade-in + slide-up)

**What to build:** Saat pengguna men-scroll ke sebuah slide foto, foto muncul dengan efek fade-in disertai gerakan slide-up yang halus. Setelah foto muncul, caption dan quote muncul secara bertahap (staggered) dengan delay antar elemen. Slide yang belum dikunjungi tampil dalam keadaan tidak teranimasikan sampai giliran mereka tiba.

**Blocked by:** 01

**Status:** completed

- [x] Dua `@keyframes` baru ditambahkan ke `globals.css`: satu untuk foto (fade-in + translateY), satu untuk teks (sama, dengan support `animation-delay`)
- [x] `PhotoSlideSection` menggunakan `IntersectionObserver` (threshold `0.6`) untuk mendeteksi slide mana yang sedang aktif di viewport dan menyimpannya sebagai state `activeSlideIndex`
- [x] `PhotoSlide` menerima prop `isActive: boolean` dan menerapkan class animasi hanya ketika `isActive` bernilai `true`
- [x] Caption muncul setelah foto (delay ~150ms), quote muncul setelah caption (delay ~300ms) — terlihat sebagai stagger yang natural
- [x] Animasi hanya trigger sekali per slide per kunjungan (tidak loop)
- [x] Animasi berfungsi di mobile dan desktop
- [x] Tidak ada dependency npm baru yang di-install

### Catatan Penyelesaian
- Menambahkan keyframes `@keyframes slide-fade-in-up` dan `@keyframes slide-text-appear` di `src/app/globals.css`, lengkap dengan utility classes:
  - `.animate-slide-enter` untuk entrance foto.
  - `.animate-slide-badge` (delay 200ms) untuk badge peran.
  - `.animate-slide-caption` (delay 150ms) untuk judul caption Pacifico.
  - `.animate-slide-quote` (delay 300ms) untuk kutipan motivasi Nunito italic.
- Memperbarui `PhotoSlideSection.tsx` untuk menghubungkan observer threshold 0.6 dengan state `activeIndex`, serta meneruskan prop `isActive={activeIndex === index}` ke setiap `PhotoSlide`.
- Memperbaiki `PhotoSlide.tsx` agar badge diletakkan di dalam text container (40vh) dengan warna pastel aslinya, serta menambahkan support animasi staggered yang natural.
- Memastikan `priority` hanya diterapkan pada slide pertama (`index === 0`) agar optimasi performa loading Next.js tetap terjaga.
- TypeScript check (`npx tsc --noEmit`) dan production build (`npm run build`) berhasil 100% tanpa error.
