# 1: Bible Verse Captions & Remove WishSection

**What to build:** Setiap foto slide menampilkan kutipan ayat Alkitab Terjemahan Baru (TB) beserta referensinya (misal "1 Timotius 4:12 (TB)") di bawah foto, menggantikan kata-kata motivasi yang ada sebelumnya. Referensi ayat tampil rata kanan di bawah teks ayat, dalam gaya Nunito kecil. Bagian "Untaian Doa & Ucapan Hangat" tidak lagi ditampilkan — slide foto ke-6 menjadi penutup alami, langsung diikuti footer.

**Blocked by:** None (dapat mulai langsung)

**Status:** ready-for-agent

- [ ] `PhotoSlideItem` interface memiliki field opsional `verseRef?: string` — aman bagi semua consumer lama yang tidak memakai field ini
- [ ] `PhotoSlide` merender `verseRef` di bawah teks ayat jika field tersedia: Nunito, ukuran kecil (`xs`/`sm`), right-aligned, format `— <referensi>`
- [ ] Ukuran font teks ayat (`quote`) diturunkan satu level agar teks panjang tidak overflow di layar kecil
- [ ] Data 6 slide di view utama diperbarui: field `quote` berisi teks ayat TB lengkap, field `verseRef` berisi referensi ayat sesuai tabel di SPEC §9
- [ ] `WishSection` tidak dirender dan data `defaultWishes` dihapus dari view utama; file komponen `WishSection.tsx` dan `WishCard.tsx` **tidak dihapus** dari filesystem
- [ ] Tidak ada `console.error` atau TypeScript error saat `npm run build`
- [ ] Semua import menggunakan alias `@/`
