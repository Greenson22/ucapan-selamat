# 2: Splash Screen + Audio Trigger

**What to build:** Saat halaman pertama dibuka, seluruh konten utama tersembunyi di balik layar penuh bergradasi pastel yang menampilkan nama "Fajar Lumenta 🎂" dan satu tombol besar ▶ Mulai di tengah. Di bawah tombol ada ayat dekoratif kecil (Amsal 23:18 TB). Ketika tombol ditekan: musik BGM mulai diputar, splash menghilang, dan konten halaman utama muncul dengan efek fade-in. Musik tidak pernah diputar sebelum ada interaksi pengguna.

**Blocked by:** 1 — view utama harus sudah bersih (WishSection dihapus, data slides diperbarui) sebelum splash diwire.

**Status:** ready-for-agent

- [ ] Komponen `SplashScreen` baru dibuat sebagai `fragment` dengan props: `name`, `onStart`, dan dua prop opsional untuk ayat dekoratif
- [ ] Latar splash menggunakan gradasi pastel (`lavender → pink → peach`) tanpa gambar eksternal
- [ ] Tombol ▶ Mulai memiliki `aria-label` deskriptif, efek hover (`scale-105`) dan active (`scale-95`), transisi smooth
- [ ] View utama memegang state `splashDone` (awal `false`) dan `audioRef` yang mengarah ke elemen audio BGM
- [ ] Menekan tombol Mulai: `splashDone` diset `true` → `audioRef.current.play()` dipanggil (dengan error handling `catch`)
- [ ] Konten utama (HeroSection, PhotoSlideSection, footer) di-mount sejak awal tapi tersembunyi via `opacity-0 pointer-events-none` selama `splashDone = false`; saat `true` berubah menjadi `opacity-100` dengan transisi 700ms
- [ ] Splash di-unmount (conditional render) begitu `splashDone = true` — tidak perlu animasi fade-out splash terpisah
- [ ] `MusicPlayer` (floating toggle) hanya dirender setelah `splashDone = true` agar tidak bentrok dengan audio trigger splash
- [ ] View utama menggunakan directive `"use client"` karena memakai `useState` dan `useRef`
- [ ] `SplashScreen` dapat diimport dari `views/` sesuai hierarki komponen (`fragment` → boleh dipakai `views/`)
- [ ] Tidak ada `console.error` atau TypeScript error saat `npm run build`
- [ ] Semua import menggunakan alias `@/`
