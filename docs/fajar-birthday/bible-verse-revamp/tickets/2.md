# 2: Splash Screen + Audio Trigger

**What to build:** Saat halaman pertama dibuka, seluruh konten utama tersembunyi di balik layar penuh bergradasi pastel yang menampilkan nama "Fajar Lumenta 🎂" dan satu tombol besar ▶ Mulai di tengah. Di bawah tombol ada ayat dekoratif kecil (Amsal 23:18 TB). Ketika tombol ditekan: musik BGM mulai diputar, splash menghilang, dan konten halaman utama muncul dengan efek fade-in. Musik tidak pernah diputar sebelum ada interaksi pengguna.

**Blocked by:** 1 — view utama harus sudah bersih (WishSection dihapus, data slides diperbarui) sebelum splash diwire.

**Status:** completed

- [x] Komponen `SplashScreen` baru dibuat sebagai `fragment` dengan props: `name`, `onStart`, dan dua prop opsional untuk ayat dekoratif
- [x] Latar splash menggunakan gradasi pastel (`lavender → pink → peach`) tanpa gambar eksternal
- [x] Tombol ▶ Mulai memiliki `aria-label` deskriptif, efek hover (`scale-105`) dan active (`scale-95`), transisi smooth
- [x] View utama memegang state `splashDone` (awal `false`) dan `audioRef` yang mengarah ke elemen audio BGM
- [x] Menekan tombol Mulai: `splashDone` diset `true` → `audioRef.current.play()` dipanggil (dengan error handling `catch`)
- [x] Konten utama (HeroSection, PhotoSlideSection, footer) di-mount sejak awal tapi tersembunyi via `opacity-0 pointer-events-none` selama `splashDone = false`; saat `true` berubah menjadi `opacity-100` dengan transisi 700ms
- [x] Splash di-unmount (conditional render) begitu `splashDone = true` — tidak perlu animasi fade-out splash terpisah
- [x] `MusicPlayer` (floating toggle) hanya dirender setelah `splashDone = true` agar tidak bentrok dengan audio trigger splash
- [x] View utama menggunakan directive `"use client"` karena memakai `useState` dan `useRef`
- [x] `SplashScreen` dapat diimport dari `views/` sesuai hierarki komponen (`fragment` → boleh dipakai `views/`)
- [x] Tidak ada `console.error` atau TypeScript error saat `npm run build`
- [x] Semua import menggunakan alias `@/`
