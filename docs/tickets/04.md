# 04: PhotoLightbox — full-screen photo viewer

**What to build:** Pengguna mengetuk atau mengklik foto di dalam slide mana pun, dan foto tersebut terbuka dalam tampilan full-screen (lightbox) dengan latar belakang gelap. Di dalam lightbox, pengguna bisa berpindah ke foto berikutnya atau sebelumnya via tombol panah, swipe kiri/kanan (di mobile), atau navigasi keyboard. Lightbox dapat ditutup via tombol ×, klik latar belakang, atau tombol `Escape`.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] `PhotoLightbox` fragment dirender sebagai overlay modal `position: fixed`, full viewport, `z-50`, latar `bg-black/85`
- [ ] `PhotoLightbox` menerima props: `slides: PhotoSlide[]`, `initialIndex: number`, `isOpen: boolean`, `onClose: () => void`
- [ ] State navigasi (`currentIndex`) dikelola secara internal di dalam `PhotoLightbox`
- [ ] Foto ditampilkan penuh dengan `next/image` dan `object-contain`
- [ ] Tombol × (tutup) di pojok kanan atas, tombol panah kiri (prev) dan kanan (next) di sisi layar
- [ ] `useEffect` menambahkan event listener `keydown` untuk `Escape` → `onClose` dan `ArrowLeft`/`ArrowRight` → prev/next saat `isOpen = true`, dan membersihkannya saat `isOpen = false` atau unmount
- [ ] Swipe gesture mobile: `onTouchStart` mencatat posisi X awal, `onTouchEnd` menghitung delta — jika > 50px ke kiri, next; jika > 50px ke kanan, prev
- [ ] Klik pada area latar belakang gelap (di luar foto) menutup lightbox via `onClose`
- [ ] `PhotoSlideSection` mengelola state `lightboxOpen` dan `lightboxIndex`; setiap `PhotoSlide` menerima `onPhotoClick` yang di-trigger saat foto diklik
- [ ] Lightbox tidak muncul saat `isOpen = false` (tidak dirender atau `display: none`)
- [ ] Tidak ada dependency npm baru yang di-install
