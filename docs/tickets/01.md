# 01: Core scroll-snap slides + wire FajarLumentaView

**What to build:** Pengguna mengunjungi `/happy-birthday/fajar-lumenta` dan menemukan galeri lama (grid statis) sudah diganti dengan 6 slide penuh layar yang dapat di-scroll secara vertikal. Setiap slide menampilkan foto asli Fajar (`1.jpg`–`6.jpg`), caption judul bergaya Pacifico, quote motivasi italic bergaya Nunito, dan badge peran. Layar "terkunci" di tiap foto saat di-scroll (scroll-snap). `HeroSection` dan `WishSection` tetap ada di atas dan bawah slide.

**Blocked by:** None (can start immediately)

**Status:** completed

- [x] `PhotoSlide` fragment merender foto (via `next/image`, `object-cover`), caption (Pacifico), quote (Nunito italic), dan badge — dalam layout vertikal `60vh` foto / `40vh` teks

### Catatan Penyelesaian
- Dibuat tipe domain `PhotoSlide` serta fragment `PhotoSlide.tsx` (`src/components/fragments/PhotoSlide.tsx`) dengan perbandingan vertikal 60vh untuk area foto dan 40vh untuk teks/caption/quote/badge.

- Type checking (`npx tsc --noEmit`) dan build Next.js (`npm run build`) berhasil 100% tanpa error.
