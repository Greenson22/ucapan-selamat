# 01: Core scroll-snap slides + wire FajarLumentaView

**What to build:** Pengguna mengunjungi `/happy-birthday/fajar-lumenta` dan menemukan galeri lama (grid statis) sudah diganti dengan 6 slide penuh layar yang dapat di-scroll secara vertikal. Setiap slide menampilkan foto asli Fajar (`1.jpg`–`6.jpg`), caption judul bergaya Pacifico, quote motivasi italic bergaya Nunito, dan badge peran. Layar "terkunci" di tiap foto saat di-scroll (scroll-snap). `HeroSection` dan `WishSection` tetap ada di atas dan bawah slide.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Tipe domain `PhotoSlide` didefinisikan dengan field: `id`, `src`, `alt`, `caption`, `quote`, dan `badge` (berisi `icon`, `label`, `variant`)
- [ ] `PhotoSlide` fragment merender foto (via `next/image`, `object-cover`), caption (Pacifico), quote (Nunito italic), dan badge — dalam layout vertikal `60vh` foto / `40vh` teks
- [ ] `PhotoSlideSection` section merender 6 instance `PhotoSlide` dalam container dengan `scroll-snap-type: y mandatory`; tiap slide `scroll-snap-align: start` dan tinggi `100vh`
- [ ] Array `defaultSlides` di `FajarLumentaView` berisi data lengkap untuk 6 foto sesuai tabel konten di SPEC (caption, quote, badge per foto)
- [ ] `GallerySection` dan import `PhotoItem`/`defaultPhotos` lama dihapus dari `FajarLumentaView`
- [ ] `PhotoSlideSection` ditempatkan di luar `PageWrapper` (full-width, tidak terkekang `max-w-6xl`) — langsung di dalam `BirthdayLayout`, antara `PageWrapper` yang membungkus Hero dan `PageWrapper` yang membungkus WishSection
- [ ] Halaman tampil tanpa TypeScript error dan tanpa `console.error` di browser
- [ ] Semua import menggunakan alias `@/`
- [ ] Badge menggunakan komponen `Badge` yang sudah ada; Typography menggunakan komponen `Typography` yang sudah ada
