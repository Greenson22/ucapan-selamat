# Components

Direktori ini berisi semua komponen UI proyek `ucapan-selamat`.

## Struktur Layer

| Folder | Layer | Deskripsi |
|--------|-------|-----------|
| `elements/` | Atom | Unit UI terkecil (Button, Badge, Typography, Icon) |
| `fragments/` | Molecule | Gabungan beberapa element (PhotoCard, WishCard, MusicPlayer) |
| `sections/` | Organism | Blok besar halaman (HeroSection, GallerySection, WishSection) |
| `layouts/` | Template | Wrapper layout (PageWrapper, BirthdayLayout) |
| `views/` | Page | Komposisi penuh satu halaman (FajarLumentaView) |

Lihat `AGENTS.md` di root proyek untuk aturan lengkap import dan penamaan.
